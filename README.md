
# Functional Genomics of L. fermentum B1 28

This repository contains the R scripts used to analyze the genome of *Limosilactobacillus fermentum* B1 28 (ATCC 14931) for the manuscript: "Functional genomics of the type strain..."

## Requirements
- R (version 4.0+)
- Packages: `tidyverse`, `readxl`, `Biostrings`, `GenomicRanges`, `rtracklayer`, `GO.db`

## Data Inputs
Before running the scripts, download the following files from NCBI and place them in the working directory:
* **Genome FASTA:** `GCF_005341425.1_ASM534142v1_genomic.fna`
* **Genome Annotation:** `genomic.gff`
*(Both available at NCBI BioProject: PRJNA477598)*


You will also need the EggNOG-mapper output file:
* **EggNOG Output:** `emapper_annotations.xlsx` 
*(Generated by submitting the extracted 1,804 clean proteins to http://eggnog-mapper.embl.de/)*

## 2. How to Run
1. Open `B128_Functional_Genomics_Pipeline.R`
2. Update `setwd()` on line X to your local folder path.
3. Run the script. It will generate all figures (in `/figures`) and supplementary tables (in `/tables`).


## Outputs
Running the script generates:
- `figures/`: All PDF/PNG plots included in the manuscript.
- `tables/`: CSV files for all supplementary data (Enzymes, Anticancer candidates, GO, KEGG, COG).
